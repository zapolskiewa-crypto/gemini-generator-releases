# Gemini Image Generator

Последовательная генерация изображений в **Gemini** и **ChatGPT** для Windows x64.
Интерфейс на русском и английском. Видео доступно в Gemini.

[Скачать установщик 1.0.3](https://github.com/zapolskiewa-crypto/gemini-generator-releases/releases/latest)

Python устанавливать не нужно. Для генерации нужны Chrome, интернет и собственные аккаунты сервисов.

## Обновления

Приложение автоматически проверяет новые версии на GitHub. Установка выполняется после согласия; кнопка «Позже» позволяет продолжить работу без обновления. Подпись и контрольная сумма проверяются автоматически, лицензия и пользовательские файлы сохраняются.

В версии **1.0.2** исправлены удаление чатов Gemini, переход между заданиями ChatGPT и загрузка референсов. Добавлены восстановление загрузки через выбор файла и сообщения о состоянии очереди. Работу генерации владелец подтвердил на домашнем ПК. Версия **1.0.3** сохраняет этот код генерации и дополнительно исправляет перезапуск после обновления; исправление проверено отдельно на собранном EXE.

Обновление с 1.0.1 предлагается после публикации подписанного манифеста. Если старая сборка выдаёт `Permission denied` при обновлении, закройте приложение и установите новую версию через Setup.exe вручную. Рабочая копия приложения должна быть закрыта перед установкой.

Этот репозиторий предназначен для распространения релизов. Ключи покупателей и закрытые ключи подписи здесь не публикуются.


## Version 1.0.3 — update restart fix

Fixes automatic restart after updating. Generation code is unchanged from the home-tested 1.0.2. When upgrading from 1.0.2 or older, the OLD updater may still display `Security validation failure: parent process has different executable!`. Close the message, open the application from its shortcut and verify version 1.0.3. Alternatively, close the app and install the new Setup over it. The fix applies to subsequent updates initiated by 1.0.3. Updates remain optional.

При обновлении со старой версии её обновлятор ещё может показать эту ошибку после замены файла. Закройте сообщение, откройте приложение ярлыком и проверьте версию 1.0.3. Альтернатива — установка нового Setup поверх старой версии. Исправление действует для последующих обновлений из 1.0.3.
