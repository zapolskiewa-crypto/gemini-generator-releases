# Gemini Image Generator

Последовательная генерация изображений в **Gemini** и **ChatGPT** для Windows x64.
Интерфейс на русском и английском. Видео доступно в Gemini.

[Скачать установщик 1.0.1](https://github.com/zapolskiewa-crypto/gemini-generator-releases/releases/latest)

Python устанавливать не нужно. Для генерации нужны Chrome, интернет и собственные аккаунты сервисов.

## Покупка и активация

- [Купить ключ / поддержка в Telegram](https://t.me/ZPL_Works)
- [Страница проекта на itch.io](https://anastasiia-shepovalova.itch.io/gemini-image-generator)

После покупки вставьте персональную ссылку itch.io целиком в поле активации приложения и нажмите «Активировать». Не передавайте её другим людям. Подписки и ограничения Google/OpenAI не входят в лицензию приложения.

## Обновления

Приложение автоматически проверяет новые версии на GitHub. Установка выполняется после согласия; кнопка «Позже» позволяет продолжить работу без обновления. Подпись и контрольная сумма проверяются автоматически, лицензия и пользовательские файлы сохраняются.

Текущая версия — **1.0.1**: восстановление подготовки заданий GPT, пересоздание служебной вкладки между заданиями, освобождение памяти ответов и подробный журнал. Обновитесь с 1.0.0 через проверку обновлений в настройках приложения. Исправления проверены на локальном стенде; длительный прогон на живом ChatGPT требует отдельной проверки.

Этот репозиторий предназначен для распространения релизов. Ключи покупателей и закрытые ключи подписи здесь не публикуются.
